# Загрузчик видео

Нативный интерфейс на SwiftUI для [yt-dlp](https://github.com/yt-dlp/yt-dlp) под macOS 14+.

Приложение запускает установленный `yt-dlp` и сам ничего не скачивает, поэтому yt-dlp обновляется отдельно (`brew upgrade yt-dlp`).

## Требования

```bash
brew install yt-dlp ffmpeg deno
```

## Сборка

```bash
./build-app.sh             # build/YTDLApp.app
./build-app.sh --install   # то же + копия в /Applications
open Package.swift         # открыть в Xcode
```

Иконка перерисовывается командой `swift scripts/make-icon.swift`.

## Возможности

- анализ ссылки: обложка, название, длительность, список форматов;
- лучшее качество, ограничение по высоте, только аудио (mp3/m4a/opus/flac/wav) или ручной выбор форматов;
- субтитры (авторские и автоматические), встраивание обложки, метаданных и глав, SponsorBlock, загрузка фрагмента;
- плейлисты: выбор элементов, архив уже скачанного;
- папка и шаблон имени, cookies из браузера, ограничение скорости;
- очередь загрузок с прогрессом, журналом yt-dlp и предпросмотром команды.
